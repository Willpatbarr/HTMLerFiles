One-Sentence Version

The Go binary now embeds and serves the built React bundle alongside the API on one port — and a test caught the classic SPA-server bug before it shipped.

Must Know

Three decisions taken before building

Assets

Embed, with dir override. Same reasoning as migrations in LAM-10 — the binary is the whole deployment. FRONTEND_DIR overrides it for dev.

Scope

Both repos. Backend serves; frontend proxies /api in dev. Without the proxy, same-origin holds in production but not in the dev loop.

Build wiring

Script now, container in LAM-29. scripts/build-frontend.sh for local work; the multi-stage image is LAM-29's job.

Two calls made during the build

  • /api/ is registered though no API exists. Otherwise Go's mux sends /api/anything to the catch-all and a typo'd endpoint returns the app shell with status 200 — which fetch() reports as a JSON parse error.
  • /healthz stayed at the root. Probes expect it there, and the ticket only asked for the API to be prefixed. Costs one extra proxy entry.
Must Know

A test failed first, and that was the point

The SPA fallback was unconditional in the first implementation: any unmatched path got index.html. That is the standard recipe, and it is subtly wrong.

What goes wrong

A browser holding a cached shell requests /assets/index-OldHash.js. The server returns HTML with status 200. The browser reports:

Uncaught SyntaxError: Unexpected token '<'

Which points nowhere near the stale hash that caused it.

The fix — Change #0005
+ // A missing file that looks like an asset is a 404, not a fallback.
+ if path.Ext(name) != "" && name != indexFile {
+ 	http.NotFound(w, r)
+ 	return
+ }

Client routes are extensionless by convention, so the extension is the signal. /docs/readme.md would 404 under this rule — the right trade against silently breaking every asset 404.

Priority Levels

Must Know
  • The SPA fallback only applies to extensionless paths (#0005)
  • /api/ is reserved so a typo'd endpoint can't return HTML 200 (#0008)
  • Frontend code must use relative URLs — never an absolute backend URL
Important
  • web/dist is gitignored except .gitkeep, which go:embed needs to compile (#0002)
  • Hashed assets get immutable; the shell gets no-cache (#0006)
  • The dev database still needs migrate baseline from LAM-10
Optional
  • The not-built 503 page (#0007) — a nicety, not load-bearing
  • README rewrites in both repos
