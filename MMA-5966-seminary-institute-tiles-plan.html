Seminary & Institute Tiles

MMA-5966 · Jira ticket · Implementation plan

One-Sentence Version

Handle two new TileType values (icon, title, tap-to-URL) — the existing tile framework does everything else.

Must Know

Check This First (blockers)

  • maltSync must have the enum values. TileType.SEMINARY / INSTITUTE live in the shared library (org.ics.mobile:maltSync). App is pinned to 24.1.0; your local checkout is old. Bump to a version that has them — if none does, we're blocked.
  • You export 2 SVGs from Figma (the book glyphs). Icons are monochrome — the green/blue in Figma is the tile background color, which the server controls.
  • Tiles won't appear until the server sends them in tiles / availableTypes. No client-side default list exists.
Template to copy: commit 5be1617133 (Temple Worker Portal tile). This ticket is that same pattern, twice.
