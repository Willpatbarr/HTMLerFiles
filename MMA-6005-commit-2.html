Watch Out For Important

  • photoPath shape: DTO docs say absolute URL, but the repo KDoc hints proxy may matter for on-device resolution — verify against one real synced public event; a fix stays confined to the use case
  • AppBarMenu itemLimit = 3: Share + QR = 2 on-bar icons is safe; a third icon would silently demote into overflow — the screen test locks this in
  • No loading flag exists. de7b880bb3 deleted it — the state is nullable and null means not loaded yet. Every preview state, screen test, and UiState copy uses null where you'd reach for loading = true. Full note on the Overview
  • Gate on EventDetails.isPublic, never EventDetailsCalendar.isPublicEventsEnabled — the latter is a calendar capability flag; using it compiles and can still pass tests. See Agent Gotchas on the Overview
